# Checklists and tables

## Checklists

Type `/`, pick **Task list**, and you get real checkboxes. Click a box to tick it.

- [ ] Read this note
- [ ] Tick this box with a click
- [x] Open Meku for the first time
- [ ] Add a task of your own below

## Tables

Pick **Table** from the `/` menu to get one like this. Click into a cell to type.

| Project | Status | Due |
| --- | --- | --- |
| Plan the trip | In progress | Friday |
| Write the report | Not started | Next week |
| Book the flights | Done | Yesterday |

> [!tip] Good to know
> Tables here are for notes and lists. They don't calculate or filter like a Notion database.

## Code

For snippets, type `/` and choose **Code block**. Anything inside keeps its spacing and uses a fixed-width font.

```
Dear team,
  this text keeps its spacing exactly.
```
