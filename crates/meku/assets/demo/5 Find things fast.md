# Find things fast

You will end up with a lot of notes. These keep them within reach.

## Four shortcuts to learn

| Press | To do this |
| --- | --- |
| `Ctrl P` | Jump to any note by typing part of its name |
| `Ctrl Shift P` | Run any command (the answer to "how do I...?") |
| `Ctrl Shift F` | Search the words inside every note |
| `Ctrl F` | Search inside the note you are in |

## Tabs

Each note you open gets a tab along the top, like a browser. `Ctrl T` starts a new note and `Ctrl W` closes the current tab.

## The sidebar

The left side lists your folders and notes. Right-click anything for options such as rename or delete. Hide it with `Ctrl \` when you want the page to yourself.

## Three ways to see a note

`Ctrl E` switches how the current note is shown:

- **Live** is the default. It looks finished, and the line you are on shows its symbols.
- **Source** shows every symbol, always.
- **Read** is a clean page with no editing.

## Make it yours

Open settings with `Ctrl ,` to change the font, theme and page width. `Ctrl Alt T` cycles through themes, and `Ctrl +` and `Ctrl -` zoom the text.
